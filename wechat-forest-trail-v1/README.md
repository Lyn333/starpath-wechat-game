# 森林寻径原生微信小游戏

这是与网页端 v1.0 对齐的原生微信小游戏 Canvas 工程，已配置 AppID `wx42d447652d8a5d07`。工程提供单棋盘随机进入、2,400 道首发题、分类耗尽后的确定性 seed 续关、按中国标准时间生成的每日挑战和本地进度保存。

## 当前原生体验

启动时会先加载 `audio` 与 `catalog` 两个普通分包，随后播放约 2.6 秒的森林主题开场动画。开场依次绘制天空、云朵、林地、树影、林径和“森林寻径”标题；任意轻触可立即跳过。开场自然结束或跳过后只会创建一次游戏实例，接着启动背景音乐，并进入既有的新手引导或单棋盘流程。

背景音乐位于 `audio/forest-trail-background.mp3` 并循环播放，受顶部“音效”开关控制。普通连线、界面按键、撤回、清空和通关均保持静音；只有合法触达当前下一个路标数字时，才会播放原创的现代日历提醒风格三段短提示。

| 数据或资源 | 位置与行为 |
|---|---|
| 首发题库 | `catalog/launchCatalog.js` 普通分包；共 2,400 道关卡。 |
| 背景音乐 | `audio/forest-trail-background.mp3` 普通分包；循环播放。 |
| 开场动画 | `core/OpeningSequence.js`；约 2.6 秒，可轻触跳过。 |
| 本地存档 | `wx.setStorageSync` 保存完成关卡、每日挑战、seed 续关和音效开关。 |

## 构建与验证

在本目录执行：

```bash
pnpm run test
pnpm run build:package
# 或一次性运行
pnpm run verify
```

`pnpm run verify` 会运行每日挑战、题库转换、开场动画、游戏流程和音频回归测试，然后生成可直接导入微信开发者工具的发布目录：

```text
/home/ubuntu/wechat-forest-trail-v1-release/
├── game.json
├── project.config.json
├── game.js
├── audio/
│   ├── game.js
│   └── forest-trail-background.mp3
└── catalog/
    ├── game.js
    └── launchCatalog.js
```

## 真机复验与提审准备

解压最新 r12 发布归档到新建空文件夹后，在微信开发者工具中按“小游戏”类型导入。点击“预览”并扫码，依次检查开场自然结束、触摸跳过、音效开关、背景音乐、数字触达提示、首次引导、每日挑战和基础连线。真机验收通过后，由账号管理员在微信开发者工具上传版本，并在微信公众平台填写审核资料后提交审核。

所有玩家完成进度仅保存在本地缓存。提交审核时应提供竖屏玩法截图、游戏内容介绍、隐私说明、版本更新说明和题库/素材授权说明。
