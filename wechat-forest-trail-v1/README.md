# 森林寻径微信小游戏 v1.0

这是与网页 v1.0 对齐的原生微信小游戏 Canvas 源工程。它采用单棋盘随机进入模式，提供 2,400 道首发关卡、分类耗尽后的确定性 seed 续关、以中国标准时间为准的每日挑战、本地进度、音效开关与多层通关庆祝反馈。

## 构建发布包

在本目录执行 `pnpm run verify`。脚本会校验每日挑战和题库转换，并将可导入微信开发者工具的成品输出到 `/home/ubuntu/wechat-forest-trail-v1-release`。题库会被置于 `catalog` 普通分包，主包保留启动逻辑，避免首发题库影响首屏包体积。

> 上传前必须在发布包根目录的 `project.config.json` 中将 `touristappid` 替换为已认证的微信小游戏 AppID，并由账号管理员在微信开发者工具中完成真机预览、上传、体验验证和提审。

## 微信审核建议

提交审核时请提供竖屏玩法截图、游戏内容介绍、隐私说明、版本更新说明和题库/素材授权说明。每日挑战采用客户端按中国标准时间确定性生成，不依赖后台定时任务；所有完成进度仅保存于用户本地缓存。
