# 森林寻径原生微信小游戏 v1.2.9

这是可直接导入微信开发者工具的原生 Canvas 小游戏工程，已配置 AppID `wx0b874c8cc868b032`。v1.2.9 提供 20,000 道原创、可复现且经过质量门禁的精品关卡，并以紧凑分桶记录按尺寸和难度懒加载，避免启动时展开完整题库。左上三层控件与棋盘左边线对齐，棋盘配色取自用户提供的「知笔墨 · 诗意中国色」色卡，默认 **肽白**；所有主题均使用原始深浅绿色连线渐变。

## 当前体验

启动流程会依次加载 `audio` 和 `catalog` 分包并播放森林主题开场动画。若精品题包加载失败，游戏会自动切换到 Seed 生成模式，而不是阻止玩家进入。控制区提供自由选题、每日挑战、**关卡挑战**和时间挑战入口；Easy、Medium、Hard、Expert 的限时通关奖励分别为 10、7、5、3 秒。

## v1.2.9 修复记录（2026-09-03）

以下问题均由 `test/gameplay-regressions.cjs` 提供回归覆盖：

- **精品题库未接入**：`GameFlow` 构造 `HybridLevelProvider` 时丢弃了 `services.catalog`，玩家实际只玩到 Seed 生成题。现已正确传入，首关来自 20,000 道精品题。
- **存档无限膨胀**：每次换题都会写入一条包含完整题目的 `activeSessions`，永不清理。现在离开未完成题时清除其存档，并对 `activeSessions` 设置 8 条硬上限（迁移旧存档时同样裁剪），存档状态版本升至 v6。
- **通关后关闭弹窗即卡死**：关闭通关弹窗后所有按钮失效，而隐藏弹窗的“继续下一题”仍可隔空点中。现在关闭后可正常换题/切模式，渲染器在弹窗隐藏时清空弹窗热区。
- **时间挑战结果弹窗无法退出**：新增右上角 `×`，关闭后回到普通模式。
- **排行榜看不到**：主域从未把开放数据域的 sharedCanvas 画到屏幕。现在“查看排行榜”会打开好友榜弹窗并持续 `drawImage` sharedCanvas；开放数据域按主域给定尺寸绘制。
- **计时器不走动**：普通/每日/关卡挑战模式新增 500ms 周期重绘，通关后冻结用时；恢复未完成局时延续已用时间。
- **时间挑战尺寸永久升级**：棋盘尺寸改为只由本局已解题数决定，`ordinal` 仅用于 Seed 去重；每局重新从档位起始尺寸开始。
- **引擎与验证器规则不一致**：`TrailEngine` 现要求最大数字必须是路径终点（与玩法说明第 3 条和 `PuzzleValidator` 一致），此前存在“覆盖全盘但未在终点结束”也被判通关的路径，导致唯一解门禁失效。

## 导入微信开发者工具

完整解压发布压缩包后，选择顶层同时包含 `game.js`、`game.json` 与 `project.config.json` 的文件夹，并以“小游戏”类型导入。测试文件已在 `project.config.json` 中加入上传忽略规则，不会进入正式小游戏包。

## 自动化验证

在安装 Node.js 的环境中执行：

```bash
npm run verify
```

该命令会检查 40 个 JavaScript 文件，验证 Seed 可复现、生成题质量门禁、规则引擎恢复、旧存档迁移、能力分、防重复、多模式流程、模式入口渲染、连线/通关音效、紧凑题库的身份与分桶完整性；离线发布校验会全量核验 20,000 道源题的标准解与紧凑记录一致性。
