# 森林寻径：200关微信小游戏

此目录是一个可独立导入微信开发者工具的小游戏关卡包。它使用导出的 **100 道 6×6** 与 **100 道 8×8** 谜题，转换为森林寻径的林径、路标、倒木和解法数据结构，并提供 Canvas 关卡选择、连续闯关和本地通关进度。

## 包含内容

| 模块 | 作用 |
|---|---|
| `data/levelBundle.js` | 自动生成的200道可玩关卡；包含完整解法，仅应置于受信任的小游戏包内。 |
| `core/TrailEngine.js` | 顺序路标、正交移动、墙体、撤回与完成判定。 |
| `core/TrailRenderer.js` | 森林寻径 Canvas 2D 路线图、脚印、路标和完成态。 |
| `core/LevelLibraryRenderer.js` | 6×6/8×8、林缘/林间/密林筛选和分页关卡目录。 |
| `core/ProgressStore.js` | 使用 `wx.setStorageSync` 保存本地通关和最佳步数。 |
| `core/GameFlow.js` | 在关卡目录与实际游戏之间切换，并在通关后解锁同组下一关。 |

## 接入微信开发者工具

将整个 `wechat-forest-trail-200` 文件夹导入微信开发者工具，保持 `game.js` 和 `game.json` 位于根目录，选择**小游戏**而非小程序页面项目。`project.config.json` 默认使用 `touristappid` 以便游客模式检查项目；进行真机调试、上传开发版与提审前，必须在开发者工具中替换为自己的小游戏 AppID。入口使用 `wx.createCanvas()` 与 `wx.onTouch*`，符合微信小游戏 Canvas 和触摸事件模型。[1] [2]

## 发布到微信小游戏

微信小游戏的标准版本流程是**真机预览 → 上传开发版 → 设置体验版 → 提交审核 → 发布**。开发者工具中完成真机预览后，点击顶部“上传”，填写递增的版本号与本次更新说明；上传完成后，在 MP 后台的“版本管理—开发版本”中找到该版本并设置为体验版。体验成员应验证 6×6、8×8 各一个难度组的首关、末关、回退、叶径提示、通关后的下一关和重启后的本地进度。

体验验证通过后，在 MP 后台对该开发版选择“提交审核”，按页面要求完成游戏内容介绍、截图、版本更新说明及游戏自审自查资料。审核通过后，具有发布权限的管理员可在“审核版本”中选择全量发布；若需要降低首次上线风险，可先使用平台提供的分阶段发布能力。上述版本流转与权限分工以微信官方发布指南为准。[3] [4]

> 本项目包含题目路径及完整解法，用于本地规则验证和“叶径提示”。正式上线前，请确认您对导入题库拥有适当的使用与发布授权，并在审核资料中如实说明游戏内容与素材来源。

## 发布前检查清单

| 检查项 | 验收标准 |
|---|---|
| 题库构建 | 在项目目录执行 `pnpm run verify`，命令输出显示 200 道关卡、进度测试和关卡流转测试均通过。 |
| 尺寸与难度 | 目录页可切换 6×6 / 8×8 与林缘 / 林间 / 密林；每个尺寸分别为 34 / 33 / 33 关。 |
| 真机触摸 | 在至少一部微信真机上验证连续拖动、倒木阻挡、撤回、叶径提示、关卡目录返回与下一关按钮。 |
| 本地进度 | 通关后退出并重启小游戏，已通关状态、最佳步数与同组下一关解锁状态应保留。 |
| 竖屏与资源 | `game.json` 保持竖屏；检查首屏、目录翻页和8×8棋盘没有文字溢出、异常黑屏或资源加载失败。 |
| 审核材料 | 提前准备游戏名称、图标、截图、内容介绍、版本更新说明与平台要求的自审材料。 |

上传、体验、审核与发布由微信小游戏账户管理员在开发者工具及 MP 后台中完成；本项目不会替用户提交审核或发布。

## 重新构建题库

源数据位于 `/home/ubuntu/unlimited-puzzle-export/export/zip_unlimited_6x6_8x8_200.json`。当源题目变更时，在本目录执行：

```bash
pnpm run verify
```

构建脚本会拒绝题目数量不是200、路径未覆盖整张棋盘、非正交移动、重复格点或路标编号不连续的题目。

## 验收标准

| 项目 | 标准 |
|---|---|
| 题库 | 6×6、8×8 各 100 关；每种尺寸包含林缘 34 关、林间 33 关、密林 33 关。 |
| 游玩 | 从 1 号路标开始，只能正交移动；重复、跳格、越墙、跳过路标均被拒绝；可撤回与重置。 |
| 连续体验 | 同一尺寸与难度组内按顺序解锁；通过一关后可进入下一条林径。 |
| 进度 | 通关状态与最佳步数保存在本地缓存；重新启动后仍可读取。 |
